# 真人試用(TestFlight 版;兩個 App 一樣)

目的:看 7 歲小孩、70 歲長輩**不看說明**時,在哪裡停住、按錯、看不懂。這比任何自動測試都準。

## 準備
- 用 TestFlight 裝最新版(步驟在 `docs/IOS.md`),或先用手機 Safari 開網頁版(GitHub Pages)。
- 刪掉 App 重裝(或在網頁版用無痕視窗),確保是「第一次打開」。
- 旁邊放一台琴(或鼓 / 打擊墊)。
- 不要先講怎麼用。對方問你時,只說「你覺得呢?」,然後記下來。

## 請對方做的事(每人約 10 分鐘)
1. 打開 App,開始練習。
2. 跟著練今天的第一段,直到 App 說「過關」或你覺得卡住。
3. 結束今天的練習。
4. 找到「自己練到第幾關」(路線圖)。
5. (會看譜的人)到「視奏」彈一題。

## 你要記的(每一步)
| 步驟 | 花了幾秒才按下去 | 有沒有按錯 / 按了沒反應 | 對方說了什麼(原話) |
|---|---|---|---|
| 第一次打開 | | | |
| 開始今天的練習 | | | |
| 第一次按 ▶ | | | |
| 按「做到了」 | | | |
| 過關後 | | | |
| 結束今天 | | | |
| 找路線圖 | | | |

特別注意:
- 有沒有超過 **10 秒**不知道要按哪裡。
- 有沒有**按了灰色、不能按的按鈕**。
- 字有沒有要**湊近才看得到**(長輩)。
- 有沒有**看不懂的字**(小孩;例如「圓滑奏」「拍點」)。

## 試完以後
把表格拍照或打字傳給 Claude,會整理進 `docs/BACKLOG.md`,照「會卡住 > 看不懂 > 不一致 > 好看」的順序修。
