# 待辦(自動迭代用)

體驗員(`uxtester`)找到的問題寫在這裡,迭代員(`iterator`)一次拿一項做,做完打勾。
格式:`- [ ] [小/中/大] 畫面 — 問題 → 建議`。外觀、新功能、刪功能要使用者先選,放「要使用者決定」。

## 可以直接做(不改外觀、不加功能)

- [ ] [小] (迭代中)視奏右手 / 雙手 — 難度鈕(1 · C4–G4…)與下面「顯示音名」「− 76 +」是三種不同的按鈕外觀與高度,上方設定卡像拼起來 → 難度改用 `.seg` 或同高同圓角的一排,「顯示音名」與速度放同一行對齊
- [ ] [小] (迭代中)第一次打開(390 寬) — 考試系統 ABRSM 選中塊右側有一小段凸起 / 括號狀邊緣,背景卡片露出一條金邊,像破圖 → 選中塊用 `.seg` 標準樣式,對話框頂端金線去掉或貼齊圓角
- [ ] [小] (迭代中)手機橫式 — 今日練習列表小字與卡片內距偏小(約 11px),與直式字級層次不一致 → 清單字級至少 `--fs-md`

## 要使用者決定
- [ ] [小] 聽力單音 — 灰掉的「下一題」(disabled)在淺色主題對比太低、右下孤單,琴鍵與「這是 C」之間留白不均 → 沒作答前不顯示或改成與「這是 C」同列,間距統一 8
- [ ] [小] 技巧音階(手機)— 樂譜右邊被切到,沒有「還有」的提示,7 歲 / 70 歲不知道可以捲 → 加右側淡出漸層或縮放到整行放得下
- [ ] [中] 桌機 1400×900 今日 / 檢定空狀態 — 內容只佔上半,下方約一半是空白,卡片左窄右寬像沒對齊 → 兩欄等高,今日卡放大字級與間距,或內容垂直置中,練習紀錄寬度與左欄對齊
- [ ] [中] 全部畫面 — 深色主題的次要字(今日練習「伴奏」淡字、底部分頁未選圖示、頁尾出處)對比偏低,長輩看不清 → 次要字淡色提高一階,頁尾字級加大;外觀決定,請先做比較圖
- [ ] [小] 檢定空狀態 — 「點下面一項開始練」一行加大空白題目卡,右下「隨機抽考」離提示很遠(手機直式約 60px 空白)→ 卡片高度收緊,按鈕與提示同一行或貼近

### 新功能(辯論員 2026-11 評過,建議順序)
- [ ] [中] 練習紀錄備份:匯出 / 匯入一個檔案(系統分享),換手機、清資料不會不見 — 上架前最該補
- [ ] [小] 里程碑:練完那一行加一句稱讚(連續 7 天、過 10 關…),不跳視窗、不排行
- [ ] [小] 給家長 / 老師的本週摘要:一段文字用系統分享(可跟備份共用分享)
- [ ] [中] 每天練習提醒(iOS 本機通知,自己選時間;要加 Capacitor 外掛;上架後)
- 不建議:視奏聽自己的錄音(隱私說明要重寫)、App 內大字開關(已跟系統文字大小)、兩小節循環(多一顆鈕,今日練習已自動慢練)
