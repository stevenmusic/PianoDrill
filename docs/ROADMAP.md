# SightDrill 路線圖(打分系統、三合一 App、上架)

## 已完成(這一輪)
- 譜面縮放不低於 ScrollScore(手機 0.9、平板 0.95、桌機 1.0)
- 出題:大跳後級進回頭、快速音符限制跳進距離(依級別)、audit 檢查
- 播放軸外觀照 FingerDrill;播放換行預看式捲動
- 「開始彈奏」:備考結束後出現,一小節預備拍,播放軸依速度自己走、自動換行,不用點螢幕
- 練習紀錄(今日題數、連續天數);版本指紋自動化(`npm run stamp`)

## 1. 打分系統(用麥克風判斷彈得對不對)
不用眼球追蹤:相機追視線不準、耗電、要相機權限、App Store 隱私審核麻煩。改用「聽」:

| 階段 | 內容 | 難度 |
|---|---|---|
| A | 單音旋律(右手)音高偵測:Web Audio + 自相關/YIN,跟預期音比對(音高、起音時間) | 中 |
| B | 節奏評分:只看起音時間(onset),容許 ±1/8 拍;不看音高也能給節奏分 | 低 |
| C | 雙手(和弦)音高:鋼琴多音偵測很難,先只評旋律線或低音線,不評整體 | 高 |
| D | 依你彈到的位置自動捲動(取代「依速度走」的播放軸) | 中,需要 A |

建議順序:B → A → D → C。B 最容易先做出「彈完給你節奏分」。評分一律給「建議」,不給考試分數(避免被誤認為官方評分)。
需求:麥克風權限說明、隱私權政策更新;在 iPhone 上要實測延遲與環境噪音。

## 2. 三合一 App(單一 App 上架)
三個工具(SightDrill 視奏、FingerDrill 指法、EarDrill 聽力)同一群使用者,合成一個 App 比較好被找到、審核也比單純網頁包殼容易通過。

先決條件(上架前必須):
1. 打分系統至少有 B+A(讓 App 不只是題目產生器)
2. 離線可用:鋼琴音色與 OSMD 內建,不依賴 `tonejs.github.io` / Google Fonts
3. 隱私權政策合併、麥克風用途說明
4. 共用外殼:底部分頁「視奏 / 指法 / 聽力」、共用的練習紀錄與每日目標
5. App 名稱與圖示(三個工具的圖示:眼睛、手、耳朵,可做成同一系列)

打包:Capacitor 把網頁包成 iOS App(只在打包時才有建置步驟,開發仍然不用 build)。
需要使用者自己:Apple Developer 帳號(年費 99 美元)、App 名稱、App Store 截圖與說明文字。
