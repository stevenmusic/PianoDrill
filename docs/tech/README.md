# FingerDrill 手指特訓

鋼琴技巧練習工具:**音階、琶音、哈農**三個練習庫,加上 **ABRSM / Trinity 檢定抽考**。給檢定的學生、上課點考的老師,也給不考試、只想練手指的人。
介面中英雙語(頂欄右上角切換)、黑金設計系統(與 ScrollScore / HarmonyMap / HarmonyHands 同一系列),手機直式優先(iPhone 放在譜架上看)。

線上版(GitHub Pages,main 根目錄):<https://stevenmusic.github.io/FingerDrill/>

## 架構:三個練習庫 + 檢定(折衷方案)

底部四個分頁:

| 分頁 | 內容 |
|---|---|
| **音階** | 自由選:大調 / 小調(和聲、旋律、自然)/ 半音階 / 全音音階 × 同向、反向、相隔三度、相隔六度、三度雙音、六度雙音 × 12 個調 × 1–4 個八度 × 右手 / 左手 / 雙手 × 圓滑 / 斷奏 |
| **琶音** | 大三、小三(原位 / 第一轉位 / 第二轉位)、屬七(解決到主音)、減七、分解和弦 × 12 個調 × 1–4 個八度 × 手 × 奏法 |
| **哈農** | 第一部分 1–20 首 × 12 個調 × 右手 / 左手 / 雙手;照原譜樣式 + 移位規則產生(見下方「哈農」);速度階梯(✓ 記錄最高速度、下一輪 +4) |
| **檢定** | ABRSM(考官點題制:隨機抽考,分手的項目指定左手或右手)/ Trinity(A、B 組:依序「下一項」整組演練或隨機抽一項),初級 + 1–8 級 |

- **第一次打開**會問「你在準備鋼琴檢定嗎?」:選了考試和級數 → 直接打開檢定分頁,音階、琶音分頁上方也會先列出這一級的要求(可收起);選「不考試」→ 純自由練習。之後隨時可在檢定分頁更改。
- 每一題都有:五線譜 + 指法(OSMD,排成一整行;比畫面短就置中,比畫面長可左右滑)、播放軸(照 ScrollScore:半透明金線,播放時停在 25%、樂譜往左捲)、
  取樣鋼琴示範(ScrollScore 的 Salamander Grand,含預備拍與拍點)、速度(− / + 點一下 ±1、按住連續增減)、熟練 / 待加強標記(localStorage,同一個要求跨分頁、跨級數共用)。
- 檢定題目預設考試速度(單位照大綱:ABRSM 1–4 級 ♩、5–8 級 𝅗𝅥;全部是平均的八分音符),可調慢練習,記住「考試速度的幾 %」。

## 檢定資料:依官方大綱逐項整理

| 系統 | 依據 | 頁碼 |
|---|---|---|
| ABRSM | *Piano Practical Grades Qualification Specification 2025 & 2026*(abrsm.org 官方 PDF);*2027 & 2028* 版音階要求逐字比對過,完全相同 | 速度表 p.14,初級 p.20、1 級 p.23 … 8 級 p.44 |
| Trinity | *Piano Syllabus — Qualification specifications for graded exams from 2023*(2026 年 2 月線上版,trinitycollege.com 官方 PDF)Technical work pathway | 初級 p.29、1 級 p.31 … 8 級 p.45–46 |

每一級都標了 `source`(頁碼),`official` / `verified` = true。資料來源檔是 `tools/build/syllabus_src.py`(改這個再執行它會重新產生 `data/syllabus.json`)。

**核對方式(兩道,彼此獨立)**
1. `python3 tools/build/crosscheck.py <ABRSM txt> <Trinity txt>`:把官方 PDF 轉成文字(`pdftotext -layout`),逐級比對每一類的調、起音、八度數,Trinity 逐組比對每一項的調、類型、指定的小調形式 → 全部一致
2. 把 PDF 頁面轉成圖片,逐格對照手、力度、奏法、八度、速度 → 全部一致(這一道抓到並修正了 Trinity 8 級 B 組 F♯ 小調反向「未指定小調形式」)

PDF 有版權,不放進 repo。取得:ABRSM https://www.abrsm.org/en-gb/piano(Cloudflare 擋 curl,要用瀏覽器開頁面再下載);Trinity https://www.trinitycollege.com/resource/?id=9079。

**大綱沒有寫死、照譜例或慣例處理的地方**

- 大綱只說「依下方譜例」的型態,這裡的做法:ABRSM 初級五度範圍 = 1-2-3-4-5-4-3-2-1(反向)/ 1-3-5-3-1(琶音);屬七解決 = 最後的屬音往上四度到主音(依 6 級頁面譜例)
- 相隔三度 = 右手比左手高十度;相隔六度 = 主音在上方、兩手相距六度;半音階相隔小三度(Trinity 7 級)= 右手高十度
- Trinity 1 級的三連音分解和弦:大綱只寫「triplet broken chords」,確切型態只印在 Trinity 付費的《Piano Scales & Arpeggios from 2015》,公開文件都沒有譜例;
  這裡用一般教材的型態(原位 → 第一轉位 → 第二轉位再下行),App 的樂譜下方也有註明。這是整份大綱唯一無法從官方公開資料確認的地方
- 雙音音階(三度、六度):只標音、不標指法(連奏三度的指法系統各版本差異大)

## 檔案結構(沒有 build step,直接部署)

```

js/musicxml.js          練習 → MusicXML(記譜規則)、播放時間表

tools/test/             自動驗證
```

## 驗證

```
node tools/test/verify.mjs                  # 不需要瀏覽器
cd tools/test && npm i && node smoke.mjs    # 瀏覽器整合測試(手機 + 桌機)
cd tools/test && node notation.mjs          # 大綱每一題實際用 OSMD 畫出來比對
cd tools/test && node layout.mjs            # 19 種裝置尺寸 × 每個畫面的版面檢查
cd tools/test && node bilingual.mjs         # 中英文版面一致(各尺寸 × 各畫面 + 大綱每一題的題目與標籤)
cd tools/test && node human.mjs 200 1       # 模擬真人觸控亂點 200 步(種子 1),每一步檢查狀態
node tools/build/stamp.mjs                  # 改了 css/js/data 之後更新版本指紋(verify 會檢查)
cd tools/test && node shot.mjs '<題目 JSON>' 名稱   # 截圖
```

- `verify.mjs`:大綱結構(ABRSM 點題制、Trinity A/B 組);指法表;大綱 443 題 + 所有調 × 所有題型 × 1–4 個八度(共 1589 種組合)的
  音高(與音程表獨立比對)、拼法、字母連續、音型(轉位、全音、屬七解決、分解和弦、雙音音程)、兩手距離(八度/十度/六度)、鋼琴音域、
  指法完整、拇指不在黑鍵、上行手指銜接可彈、5 指只在兩端;MusicXML 時值與記譜規則(符桿、臨時記號、休止符、連桿、三連音、加線 ≤ 3 條)
- `smoke.mjs`:第一次打開的問題、ABRSM 抽考、Trinity 整組依序、音階/琶音每個選項都畫得出譜且指法數字都在、中英切換(英文模式沒有殘留中文)、
  播放、節拍器 ±1 與按住連續、熟練標記存起來、沒有橫向捲動、沒有 console 錯誤
- `notation.mjs`:大綱 443 題實際畫譜,OSMD 畫出的臨時記號、指法數字、8va 與我們寫的一致
- `layout.mjs`:折疊機 280、SE 320、各種 iPhone/Android 直橫、iPad 各尺寸直橫、筆電、桌機、1080p、窄視窗:沒有橫向捲動、元素不出界、
  按鈕文字不被截斷、點擊區域夠大、頂欄不重疊、底部分頁列不蓋住內容、對話框放得下、樂譜短的置中 / 長的可左右滑
- `bilingual.mjs`:11 種尺寸 × 對話框/檢定/音階/琶音/哈農,中文與英文各量一次每個元素的高度與頁面總高,要完全相同;
  大綱每一題的題目與標籤也逐題比對行數(英文太長就縮短)
- `human.mjs`:iPhone、SE、iPad(觸控)與桌機,隨機切分頁、點選擇器、抽題、連點播放、按住 ±、拖速度、中英切換、改考試、旋轉螢幕、重新整理、播放中做別的事……
  每一步檢查:沒有錯誤、播放狀態跟按鈕一致且不會兩份同時播、題目清空時不再播、樂譜指法數字都在、播放軸在紙張裡、速度一致、分頁一致、沒有橫向捲動

> 自動驗證只能確認「可彈、合規則」,不能確認是不是你慣用書上的那一種指法——下面的指法表請一併看過。

## 哈農(第一部分 1–20 首)

- `js/hanon.js`:每首只記「上行第 1 小節、下行第 1 小節(第 15 小節)的 8 個音 + 指法」,其餘用移位規則產生(上行每小節 +1 級、下行每小節 −1 級,各 14 小節,結尾主音二分音符;兩手平行八度)。
- 來源:IMSLP #00874(Schirmer 版 Part I)。逐首把第 1 小節與第 15 小節(下行轉折處)用加了音高格線的放大掃描圖讀出來,並核對第 3、20 首的結尾;第 20 首從 E 開始、結尾是和弦(右手 E3 + C4、左手 C2 + C3)。
- 調:預設只有原譜的 C 大調;按「其他調…」才展開 12 個調(進階,同一組級數換成該調的大音階,右手起音在 C3 附近,指法照 C 大調原譜)。
- 速度階梯:按 ✓ 記錄這首的最高速度,下一輪 +4(原譜建議 ♩ = 60 → 108)。
- 拍點:♩(每 4 個音一拍,原譜的速度記法)或 ♪(每 2 個音一拍,比較好數;樂譜不變,速度數字 ×2,最高速度一律記成 ♩)。
- 節奏變化:原譜(十六分)/ 附點(長短)/ 反附點(短長);附點寫成附點十六分 + 三十二分(兩個音 = 一個八分音符),小節、拍號、速度都跟原譜一樣。哈農的譜號一小節換一次(不在小節中間來回跳)。

## 練習輔助
- 速度卡下方三個選項:**循環播放**(播完自動再來一輪,有預備拍)、**每輪 +4**(循環時每輪快 4,速度階梯)、**只聽拍點**(不放示範,自己彈)
- 練習時螢幕保持亮著(手機放在譜架上不會暗掉,Screen Wake Lock)
- 桌機快捷鍵:空白鍵 播放/停止、↑ ↓ 速度 ±1、N 下一題(檢定)
- 檢定**模擬考**:ABRSM 從抽考範圍隨機點 8 項(不重複,像考官點題)、Trinity 整組依序;每項自己按 ✓ / ⚠,結束時顯示通過/待加強/未標記
